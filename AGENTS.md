
# Project Rules

## Design
- Follow DESIGN.md for all relevant project work.
- Read relevant DESIGN.md sections before planning or changing affected features.
- Report conflicts with DESIGN.md before implementation.
- No Breaking Change, No Refactoring, No Rewrite

## Source
- Write source code comments in English.
- Write repository documentation in English.

## Git
- Use Conventional Commits for all commit messages.

## Approval
- Never modify code without explicit "APPROVED".
- Propose changes before requesting approval.
- Read-only analysis does not require approval.

## Boundaries
- Never modify, MUST NOT MODIFY AGENTS.md or DESIGN.md
- Never commit secrets.
- Never force push to master.
