# Time Recorder Features

Time Recorder helps users record commutes, check bus arrivals, and manage daily schedules in Hong Kong time.

## Commute Recording

- Record commute milestones, including departure, boarding, alighting, and arrival.
- Use Smart Next to select the next suggested action.
- Record custom transport options.
- Review daily timelines, past records, and charts.
- Export and restore recorder data with JSON files.

## Bus Arrivals and Widget

- Check KMB 38 and 42C arrival estimates.
- Track arrivals during a commute and view cached countdowns.
- Access recording actions and bus arrivals from the home-screen widget.

## Audio Profiles

- Set Default, Office, and After Work volume profiles.
- Adjust ring, notification, media, alarm, and system volumes separately.
- Switch profiles automatically at configured working-day times.
- Use Default on weekends, public holidays, and personal leave days.
- View the current profile and next change, or test and apply a profile manually.
- Restore After Work Volume Profiles when commute got "After Work" is clicked and overwrite the Office Profile even within time period

## Alarms

- Create multiple alarms for every day or working days only.
- Skip public holidays and personal leave days for working-day alarms.
- Recognize personal leave from all-day calendar events titled `放假`.
- Choose alarm volume and use full-screen Snooze or Stop controls.
- Snooze for 10 minutes and restore the previous alarm volume after ringing.
- Check required permissions and test an alarm one minute ahead.

## Calendar and Private Events

- View Hong Kong public holidays, system-calendar events, private events, and related tasks together.
- Create private events for a full day or a specific start and end time.
- Keep private events separate from System Calendar.

## Reminder Rules and Tasks

- Match system-calendar events by title keywords, or assign rules directly to private events.
- Add notifications before, on, or after an event date, including daily date ranges.
- Set multiple notification times and hour-based reminders for timed events.
- Create related tasks with completion windows and separate preparation steps.
- Choose eligible weekdays, allow Saturday mornings, and optionally exclude public holidays.
- See today's required tasks, upcoming tasks, last-day notices, and overdue status.
- Keep active tasks visible in an in-app banner until completed or expired.
- Mark tasks complete and undo completion without completing unrelated tasks.
- Edit rules and nested tasks in full-screen forms while retaining unsaved parent edits.

## Rule Preview and Testing

- Preview a rule using a sample event date and optional start and end times.
- Inspect generated tasks, eligible dates, notification times, and warnings.
- Preview unsaved rules without changing saved events or task completion.
- Send sample notifications to check their appearance, sound, and vibration.
